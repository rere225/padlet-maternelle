❓ Aide

🏠 L'application : un lanceur + 4 sous-apps

La page d'accueil est un lanceur avec 4 outils :

  • 📚 Padlet d'activités — explorer les thèmes et activités
  • 📅 Planificateur — organiser la semaine
  • ⭐ Mes favoris — accéder à tes activités préférées
  • ⏱️ Minuteur — compte à rebours visuel pour la classe

Bouton 🏠 Lanceur dans chaque sous-app pour revenir.

🌐 Contrôles globaux (haut à droite, toujours visibles)

  • 🎨 Saveur — choisis un thème comme ambiance globale (les couleurs s'appliquent partout)
  • 🌙/☀️ — bascule mode sombre / clair
  • ❓ — cette aide
  • ⚙️ — panneau administrateur

📚 Padlet : explorer les activités

  • Affichage : par catégorie (Fêtes, Animaux, Sciences, etc.), A à Z, ou ordre par défaut
  • 🔍 Filtre avancé — cherche dans toutes les activités par type/durée/lieu
  • Dans un thème : Trier par défaut, A à Z, par type, par durée, par notes ⭐ ou 🎯 par domaine d'apprentissage (Programme préscolaire québécois)
  • 🎲 Surprends-moi — activité au hasard pour l'inspiration de dernière minute

📔 Personnaliser une activité

Chaque activité a ses méta-données 🏠 Lieu, 👥 Taille de groupe, 🤫 Niveau de bruit, 🎯 Compétences MEQ, et ton espace personnel :

  • ⭐ Évaluation — note de 1 à 5 après l'activité
  • 🏷️ Étiquettes — tes propres mots-clés
  • 📔 Notes — ce qui a marché, ce qu'il faut adapter
  • 📷 Photo — image prise en classe (max 2 Mo)
  • Bouton ⭐ sur chaque carte pour ajouter aux favoris

📅 Planificateur hebdomadaire

  • Vue Lundi-Vendredi ; navigation par semaine avec ◀ ▶ et « Aujourd'hui »
  • + Ajouter dans un jour : picker avec recherche
  • 🧰 Liste de matériel : agrège tout le matériel de la semaine (dédupliqué, imprimable)
  • Depuis une activité : 📅 Au planificateur pour l'ajouter directement

⏱️ Minuteur

  • Compte à rebours plein écran pour projection en classe
  • Le personnage et les items s'adaptent à la saveur active (ex. saveur Dinosaures → 🦕 mange des 🌿)
  • Tu peux personnaliser le personnage et les items de chaque thème dans ⚙️ Admin → Thèmes → ⏱️ Minuteur thématique

🖨️ Pour la classe

  • 🖨️ Imprimer (dans une activité) — version papier propre (matériel + déroulement + astuce)
  • 🖥️ Plein écran — projection TBI avec gros texte

⚙️ Panneau admin

  • 📝 Activités — modifier / supprimer / ajouter une activité (avec lieu, groupe, bruit, compétences MEQ)
  • 🎨 Thèmes — créer / modifier un thème (couleurs, emojis décoratifs, et personnage du minuteur)
  • 💾 Données — exporter / importer ton JSON, et choisir le pack d'emojis (système, Twemoji, Noto, OpenMoji couleur, OpenMoji noir pour impression)

💾 Sauvegarde

Tout est enregistré dans localStorage (par navigateur, par ordi). Pour ne rien perdre : ⚙️ → Données → « Exporter mes données » de temps en temps. Le fichier JSON contient tout (thèmes, activités, favoris, planifications, notes, photos).

📤 Partager avec un collègue

  • Envoie le fichier padlet.html (ou pointe l'URL si tu l'as déployé en ligne) — la personne a les … activités de base dès l'ouverture
  • Pour partager tes ajouts personnels : exporte ton JSON et envoie-le. La personne importe via ⚙️ → Données

🐛 Problèmes courants

  • Mes changements ne s'affichent pas → Ctrl+F5
  • Le fichier ne s'ouvre pas → clic droit → Ouvrir avec → ton navigateur
  • J'ai tout perdu → ⚙️ → Données → Réinitialiser, puis importer ton dernier export si tu en as un
  • Emojis bizarres / qui clignotent → ⚙️ → Données → Pack d'emojis → « Système » (défaut natif, toujours stable)

⌨️ Raccourcis

  • Échap — fermer modale / présentation / picker
  • Ctrl+F5 — rafraîchir en forçant
