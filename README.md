# 🌈 Mes outils de classe — Guide d'utilisation

Une suite d'outils pour la **maternelle 5 ans** dans un seul fichier HTML.
**45 thèmes · 495 activités** + planificateur, favoris, minuteur thématique, panneau admin, packs d'emojis, mode sombre.
Aucune installation, aucun compte, fonctionne hors ligne (sauf packs d'emojis tiers).

---

## 🚀 Démarrage en 30 secondes

1. Reçois le fichier `padlet.html` (ou ouvre l'URL si déployé en ligne).
2. Double-clique pour l'ouvrir dans ton navigateur (Firefox, Chrome, Edge, Safari).
3. Une fenêtre de bienvenue te guide la première fois.

> 💡 Si le double-clic ne fonctionne pas : clic droit → **Ouvrir avec** → choisis ton navigateur.

---

## 🏠 Architecture : un lanceur + 4 outils

La page d'accueil est un **lanceur** avec 4 cartes :

| App | Description |
|---|---|
| 📚 **Padlet d'activités** | Explorer les thèmes et activités |
| 📅 **Planificateur** | Organiser la semaine et la liste de matériel |
| ⭐ **Mes favoris** | Tes activités marquées d'une étoile |
| ⏱️ **Minuteur** | Compte à rebours visuel pour les ateliers |

Chaque sous-app a un bouton **🏠 Lanceur** pour revenir.

## 🌐 Contrôles globaux (toujours visibles en haut à droite)

| Bouton | Fonction |
|---|---|
| 🎨 | **Saveur** — choisir un thème comme ambiance globale (couleurs + décor partout) |
| 🌙 / ☀️ | Mode sombre / clair |
| ❓ | Aide intégrée |
| ⚙️ | Panneau administrateur |

La saveur sélectionnée s'applique à toutes les sous-apps, y compris le minuteur (qui change de personnage et d'items en fonction).

## 📚 Padlet : explorer les activités

### Trois modes d'affichage des thèmes
- **📂 Par catégorie** : groupes visuels (Fêtes, Saisons & nature, Animaux, Sciences & corps, Apprentissages, Social & émotions, Imaginaire & culture, Vie quotidienne)
- **🔤 A à Z** : alphabétique
- **🎲 Ordre par défaut**

### Recherche et accès rapide
- **Barre de recherche** — cherche dans titres, matériels, déroulements, tes notes, étiquettes
- **🔍 Filtre avancé** — applique des filtres (type/durée/lieu) à **toutes** les activités, tous thèmes confondus
- **🎲 Surprends-moi** — activité au hasard

### Dans un thème : tri des activités
Menu déroulant **Trier** :
- Ordre par défaut
- 🔤 A à Z / Z à A
- 🏷️ Par type
- ⏱ Durée croissante / décroissante
- ⭐ Mes mieux notées
- **🎯 Par domaine d'apprentissage** (Programme préscolaire québécois 2021) — regroupe les activités en sections :
  - 🤸 Physique et moteur
  - 💖 Affectif
  - 🤝 Social
  - 💬 Langagier
  - 🧠 Cognitif

Plus boutons-filtres par **type** (bricolage, motricité, cuisine, etc.).

## 📔 Personnaliser une activité

Chaque activité affiche en plus du contenu pédagogique :
- 🏠 **Lieu** (intérieur / extérieur)
- 👥 **Taille de groupe** (individuel / petit / grand)
- 🤫 **Niveau de bruit** (calme / moyen / bruyant)
- 🎯 **Compétences MEQ** (1 à 6)

Ton espace personnel :
- **⭐ Évaluation 1-5** — clique les étoiles
- **🏷️ Étiquettes** — tes propres mots-clés
- **📔 Notes** — texte libre
- **📷 Photo** — image prise en classe (max 2 Mo)

Bouton **⭐** sur chaque carte pour ajouter aux favoris.

## 📅 Planificateur hebdomadaire

- Vue Lundi-Vendredi

## ⚙️ Panneau administrateur

Le bouton **⚙️** en haut à droite ouvre la zone admin avec **3 onglets** :

### 📝 Activités
- Choisis un thème dans le menu déroulant
- ✏️ Modifier (tous les champs : titre, type, durée, lieu, groupe, bruit, compétences MEQ, matériel, déroulement, astuce)
- 🗑️ Supprimer
- ➕ Ajouter

### 🎨 Thèmes
- ✏️ Modifier (titre, emoji, couleurs avec sélecteurs, emojis décoratifs)
- **⏱️ Minuteur thématique** — personnage, item, item final personnalisables par thème, avec aperçu en direct
- 🗑️ Supprimer (et toutes ses activités)
- ➕ Créer un nouveau thème

### 💾 Données
- **🎨 Apparence** : pack d'emojis
- **📤 Exporter** : télécharger une sauvegarde JSON complète
- **📥 Importer** : restaurer un fichier reçu
- **⚠️ Réinitialiser** : revenir aux 495 activités d'origine (perd les ajouts personnels)

## 💾 Sauvegarde et persistance — IMPORTANT

Tes modifications (activités, thèmes, favoris, planifications, notes, photos, étiquettes, personnages du minuteur, préférences de saveur/dark mode/pack d'emojis) sont enregistrées dans le `localStorage` du navigateur. Elles restent quand tu fermes l'onglet ou éteins l'ordinateur, **mais sont liées à ce navigateur sur cet ordinateur**.

### Règle d'or
**Exporte régulièrement** :
1. ⚙️ Admin → 💾 Données → **📤 Exporter mes données**
2. Garde le fichier `padlet-maternelle-AAAA-MM-JJ.json` (Google Drive, OneDrive, clé USB)

Pour restaurer : **📥 Importer des données**.

> ⚠️ Les **photos** prennent de l'espace de sauvegarde. Si tu reçois une erreur « Pas assez d'espace », supprime-en quelques-unes ou utilise des images plus petites.

## 🎯 Cas d'usage typiques

**Planifier ma semaine vendredi soir**
→ 📅 Planificateur → semaine suivante (▶) → pour chaque jour, **+ Ajouter** → choisis une activité → 🧰 Liste de matériel → 🖨️ Imprime

**Trouver une activité de cuisine pour vendredi après-midi**
→ Recherche « cuisine » dans Padlet, OU choisis un thème → filtre « cuisine »

**Activité de 15 minutes à la dernière minute**
→ 🎲 Surprends-moi, OU 🔍 Filtre avancé → durée Courte

**Préparer mes activités pour les comptes-rendus MEQ**
→ Dans un thème → Trier → **🎯 Par domaine d'apprentissage** → tu vois les activités regroupées par domaine (physique, affectif, social, langagier, cognitif)

**Adapter l'ambiance à la période de l'année**
→ 🎨 Saveur → « Cabane à sucre » au printemps, « Halloween » en octobre, etc.

**Faire un minuteur thématique pour les ateliers**
→ Active la saveur du moment → ouvre le ⏱️ Minuteur → le personnage et les items correspondent automatiquement à la saveur

**Projeter au TBI pour expliquer aux enfants**
→ Active une saveur pour l'ambiance → ouvre une activité → 🖥️ Plein écran

**Imprimer des fiches sans gaspiller d'encre**
→ ⚙️ → Données → Pack d'emojis → **OpenMoji noir** → 🖨️ Imprimer
